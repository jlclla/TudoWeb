# TudoWeb
# 📊 Sistema de Pesquisa de Satisfação do Cliente para  Empresa de Marketing "TudoWEB"

**Uma pesquisa em Python, desenvolvido para coletar, processar e analisar o feedback de clientes de forma simples e automatizada. Gerando dois Relatórios o Primeiro de Teste com 10 entrevistados e o Relatório Final com total de 50 entrevistados, nesses relatórios aparecem quantas pessoas votaram em cada categoria.**
